재물운·직장운·애정운·건강운·대인운과 12개월 캘린더, 오각형 운세 그래프, 오늘의 포춘쿠키,

- **구성**: `index.html` (모든 로직·디자인 포함, 외부 라이브러리 없음), `ads.txt` (Google AdSense)
- **계산 방식**: 입춘·12절기를 태양황경으로 계산해 년주·월주를 세우고, 일진은 율리우스일 기반 60갑자 순환으로 계산합니다. 음력 입력은 1900~2049년 음양력 테이블로 변환합니다.
- **수익화·체류 요소**

  - 오늘의 포춘쿠키 — 탭하면 깨지는 인터랙션, 오늘의 한 줄·행운 숫자·행운 컬러·개운 아이템
