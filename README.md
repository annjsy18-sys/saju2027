# 2027 정미년 무료 사주풀이 · AI 신년운세

생년월일시로 사주팔자(천간·지지)를 세우고 오행·십성을 계산해 2027 정미년(丁未年)의
재물운·직장운·애정운·건강운과 월별 흐름, 개운법을 보여주는 단일 HTML 페이지입니다.

- **주소**: https://annjsy18-sys.github.io/saju2027/
- **구성**: `index.html` (모든 로직·디자인 포함, 외부 라이브러리 없음), `ads.txt` (Google AdSense)
- **계산 방식**: 입춘·12절기를 태양황경으로 계산해 년주·월주를 세우고, 일진은 율리우스일 기반 60갑자 순환으로 계산합니다. 음력 입력은 1900~2099년 음양력 테이블로 변환합니다.
- **개인정보**: 서버가 없는 정적 페이지로, 입력값은 브라우저 안에서만 계산되고 전송·저장되지 않습니다.
- **광고**: `ca-pub-3049180763400654` 메타태그와 심사 스크립트, `ads.txt` 가 포함되어 있습니다.
